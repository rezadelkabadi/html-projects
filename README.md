# پروژه‌های HTML من

این مخزن شامل پروژه‌های HTML است که در مسیر یادگیری طراحی وب توسعه داده‌ام. هر پروژه در یک پوشه مجزا با نام شماره‌گذاری شده (مانند `01_first_project`) قرار دارد و فایل اصلی آن `index.html` نام دارد (به جز مواردی که نام دیگر ذکر شده).

## فهرست پروژه‌ها

| شماره | نام پروژه | توضیح |
|-------|-----------|-------|
| ۰۱ | اولین پروژه | صفحه "سلام دنیا" ساده |
| ۰۲ | صفحه شخصی | معرفی با عکس و علایق |
| ۰۳ | برنامه هفتگی | جدول برنامه مطالعه |
| ۰۴ | فرم ثبت نام | فرم ورود اطلاعات کاربر |
| ۰۵ | وبلاگ ساده | ساختار اولیه وبلاگ |
| ۰۶ | وبسایت شخصی | صفحه کامل با header, main, footer و المان‌های audio و تصویر |

> 📌 برخی پروژه‌ها شامل فایل‌های جانبی (تصویر، صدا) در پوشه‌های `img` یا `audio` هستند.

هر پروژه را می‌توانید با باز کردن فایل `index.html` (یا فایل HTML مربوطه) در مرورگر مشاهده کنید.  
مثلاً برای پروژه اول:
